# Sales Data Analysis

## Project Description

### English

The application aims to analyze sales data by tracking customer orders, products, sales quantities, order dates, sales territories, shipping methods, and financial details.

The project helps identify sales trends, analyze product and regional performance, and provide insights that can contribute to better business decisions and improved sales performance.

### العربية

يهدف التطبيق إلى تحليل بيانات المبيعات من خلال متابعة طلبات العملاء، والمنتجات، وكميات البيع، وتواريخ الطلبات، والمناطق الجغرافية، وطرق الشحن، والتفاصيل المالية.

يساعد المشروع في تحديد اتجاهات المبيعات، وتحليل أداء المنتجات والمناطق المختلفة، واستخراج Insights تساهم في تحسين القرارات التجارية ورفع كفاءة أداء المبيعات.
